## 一、课程回顾与基础数学
1. **课程框架**：理论、动手实践、应用三者互相驱动。
2. **导数定义**：使用极限定义导数，用几何示意图解释导数是曲线切线斜率。
3. **线性代数基础**
    - 矩阵加法、哈达玛积（逐元素相乘）；提供Numpy示例代码。
    - **向量内积**：衡量向量相似度，公式 $inner(\vec x,\vec w)=|\vec x||\vec w|\cos\theta$；神经网络神经元本质就是输入向量与权重向量做内积再加偏置。
4. **二维线性分类**：使用直线 $\(y=mx+c\)$ 作为分类分隔边界，$m$ 斜率，$c$ 纵轴截距；推广至高维，直线变成超平面。

## 二、线性分类器（Linear classifier）
### 1. 逻辑回归二分类
- 训练集 $D=\{x_i,y_i\},y_i\in\{0,1\}$，使用sigmoid函数建模条件概率：
$$p(y=1|x,w)=\sigma(w^Tx)=\frac{1}{1+\exp(-w^Tx)}$$
- Logit变换：对数几率 $\log\frac{p(y=1|x,w)}{p(y=0|x,w)}=w^Tx$。
- **决策规则**：$\hat y=\arg\max p(y|x,w)$；线性分类器判定 $\hat y=1$ 等价 $w^Tx>0$，属于贝叶斯最优分类器。
### 2. 多分类决策区域
特征空间被划分为多个决策区域 $R_i$，由判别函数最大值确定；决策边界是判别函数取值相等的位置，还可以设置拒绝区域。
### 3. 图像上的线性分类
1. RGB图像：例如32×32×3图片展平为3072维向量。
2. 模型表达式：$\boldsymbol{\(\boldsymbol{f(x,W)=Wx+b}\)}$；$W$权重矩阵，$b$偏置，输出每个类别的分数。把像素拉伸为列向量，矩阵乘法得到各类得分。
3. 本质：每一类对应一条线性判别边界。
### 4. 文本数据线性建模
- 序列数据：输入输出都是序列（对话、机器翻译），可以用LSTM编码器‑解码器架构。
- 独热向量One‑hot：用来表征离散文本/类别，类别之间没有内置语义关系。

> 问题引出：当我们**不知道怎么手工设计特征表示**时，就要用到迁移学习。

## 三、迁移学习 Transfer Learning
> 核心定义：利用资源充足的源领域/源任务学到的知识，帮助训练**数据不足的目标任务**。源（source）代表数据充足，目标（target）代表低资源任务；当源模型学到通用、与领域无关特征时迁移效果最好，典型例子：ImageNet预训练。

### 传统机器学习 vs 迁移学习
1. 传统机器学习：每个任务从零独立训练一套学习系统。
2. 迁移学习：源任务学习得到通用知识，迁移给目标任务，不用从头训练。

深度网络学习分层特征：底层网络学习通用模式（边缘、形状），中层学习纹理部件，高层才学习任务专属概念；因此底层网络具备很强可迁移性。

### 深度迁移学习三大类型
1. **基于表示（Representation‑based /特征提取Feature Extraction）**
    - 冻结预训练模型的底层全部权重，**仅训练新增的分类头**。
    - 适用场景：目标数据集很小（<1000样本）；计算开销低，只更新分类头参数。预训练模型充当固定的特征提取器，可以把输出特征喂给SVM等浅层模型。
2. **基于模型共享（Model Sharing‑based /微调 Fine‑Tuning）**
    - 解冻部分/全部预训练深层网络，在目标数据集继续更新权重，适配新领域。
    - 适用场景：目标数据集规模中等（1000‑50000样本）；内存开销中等偏高，存在过拟合风险。
    - 两种实操：部分微调、全量微调。
3. **基于实例（Instance‑based）**
    - 不对模型权重改动；对源域样本做过滤、重加权：丢弃和目标域差异大样本，给相似源样本赋予权重，修正分布差异。
    - 适合源域与目标域条件分布一致，边缘分布不一样。

### 决策矩阵：三种训练方案对比
|方案|目标数据量|域相似度|过拟合风险|显存占用|
| ---- | ---- | ---- | ---- | ---- |
|特征提取|＜1000|高|低|低|
|微调|1000‑50000|中~低|中‑高|中‑高|
|从零训练|＞50000|很低|高|最高|

### 大模型辅助数据增强（迁移学习配套，解决小数据集）
当目标任务数据太少，可利用LLM生成标注数据：
1. 查询‑文档对生成：根据文档生成相关查询，用于检索任务。
2. 文本增强：同义改写生成多样样本。
3. 生成三元组样本（查询、正例文档、难负例文档）。
4. LLM自动标注无标签数据；对比人工标注，大模型生成速度快、成本低，但效果略低于人工标注。

### 多模态迁移示例
1. 图像：VGG、ResNet等ImageNet预训练骨干网络。
2. 文本：ModernBERT，支持8192长上下文，旋转位置嵌入、GeGLU激活。
3. 语音‑文本：SONAR模型，输出句子级多模态嵌入，实现语音、文本的统一表征。

## 四、本地大语言模型 Local Large Language Model
### 1. 什么是LLM
基于Transformer架构，在海量文本、代码上训练；本质预测下一个token；商业LLM一般通过API调用。

### 2. 使用本地LLM的优势
1. **隐私安全**：提示词不会离开本地机器，保护敏感数据；
2. **离线可用**，不需要联网；
3. 高度自定义：可配置CPU线程、温度、上下文窗口、GPU参数；
4. 节约成本，不需要订阅付费API。

### 3. 使用本地LLM的两种方式
1. **图形化软件工具**：Jan、Llamafile、LM‑Studio，开箱即用。
2. **代码调用**
    - HuggingFace Transformers库加载本地模型权重（示例GPT‑2）；
    - Ollama库，简单Python接口调用本地开源模型（Llama3、Mistral等）。

### 4. 硬件内存计算公式
$\text{内存(GB)}=\frac{\text{参数量} \times \text{量化bit数}}{8}+2\ \text{GB（KV缓存/上下文窗口）}$
FLOPs随参数量增大，7B模型每个token约14B FLOPs，70B每个token约140B FLOPs。

课件给出不同参数量模型（<4B、7‑9B、14‑32B、70B+）对应的最小显存、推荐硬件、性能预期，列举Qwen、Gemma、Llama、DeepSeek等主流开源模型的优缺点。

### 5. 选型考量点
- 延迟vs吞吐：小模型延迟低适合实时任务；大模型吞吐适合批量处理；
- 需要权衡：上下文窗口大小、推理速度、硬件显存、能力、许可协议。
